# Exemple : Atelier Fagne & Fil (client fictif)

Client inventé pour tester et démontrer le starterkit. Toutes les données sont fictives.

- `doc/` et `charte/` : ce que le chef de projet dépose dans `.knowledge/`
- `client.md` : la fiche produite par `/onboard` à partir de ces documents

Les pièges volontaires (contraste non conforme, zone d'intervention contradictoire, page évoquée hors arborescence, devis dans `private/`) servent à vérifier que `/onboard` les détecte.

Pour rejouer le test : copier `doc/` et `charte/` dans `.knowledge/`, puis lancer `/onboard`.
