# photos/ — Copie locale du Drive partagé (non versionnée)

Les photos du projet sont stockées sur le **Drive partagé**. Le lien se trouve dans `.knowledge/client.md` (section *Liens*).

Ce dossier en est une **copie de travail locale** : Git l'ignore, sauf ce README et `.gitkeep`.

## Reprise d'un projet
1. Ouvrir le lien Drive indiqué dans `client.md`.
2. Télécharger (ou synchroniser) le dossier photos ici, dans `.knowledge/photos/`.
3. Les agents pourront alors regarder les images, proposer des alt-texts et les envoyer sur Webflow.

## Règles
- Le Drive est la référence : toute nouvelle photo y est d'abord déposée, puis copiée ici.
- Nommage : `[page]-[sujet]-[n].jpg` (ex : `accueil-equipe-01.jpg`).
- Poids : < 500 Ko, WebP ou JPG 2000 px de large maximum.
